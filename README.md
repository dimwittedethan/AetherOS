# AetherOS

AetherOS is an **experimental, independent Linux distribution built on openSUSE**, designed to provide a clean, beginner-friendly and easy-to-use Linux experience.

AetherOS aims to offer the **simplicity and beginner-friendly experience people often look for in Ubuntu, without the unnecessary bloat**. The goal is a system that gives you what you need, stays clean, and doesn't overwhelm you with software you may never use.

## 💻 Two Editions

AetherOS is available in two ISO editions, allowing you to choose the experience that best suits your hardware.

### 🌅 Horizon

**Horizon** is designed for **modern PCs and newer hardware**.

It provides the full AetherOS experience, with a modern desktop and features intended for capable systems.

### 🌌 Aurora (Coming Soon)

**Aurora** is designed for **older, lower-end and less powerful PCs**.

It focuses on keeping resource usage lower while still providing a comfortable and usable desktop experience, helping give older hardware a second life.

Both editions share the same AetherOS philosophy and are designed to be easy to install and use.

With the expected release date of around September to December 2026.

## 🐧 Made for Beginners

Never used Linux before? That's okay.

AetherOS is designed to make switching from Windows or another operating system as straightforward as possible.

The goal is to provide:

* An easy installation process
* A familiar and straightforward desktop experience
* Sensible defaults
* Useful software included out of the box
* Minimal unnecessary software
* A clean and understandable system
* Hardware-specific choices through Horizon and Aurora

You shouldn't need to be a Linux expert just to use your computer.

---

## 🦎 Built on openSUSE

AetherOS is built on **openSUSE**, using it as the foundation while adding AetherOS-specific configuration, branding, packages, desktop customisation and other improvements.

AetherOS builds on the work of the openSUSE community and the wider Linux ecosystem rather than trying to reinvent everything from scratch.

## 📦 Ubuntu Simplicity, Without the Bloat

AetherOS is inspired by the idea of making Linux **simple and accessible to everyone**.

If you've considered Ubuntu because it's beginner-friendly and easy to get started with, AetherOS aims to provide that same approachable experience while keeping the default installation **cleaner and more focused**.

Instead of filling your system with applications and services you may never use, AetherOS aims to provide the essentials and leave the rest up to you.

**Simple like Ubuntu. Clean like AetherOS.**

## ⚠️ Experimental Software

AetherOS is still under development. You may encounter:

* Bugs and unexpected behaviour
* Missing or unfinished features
* Breaking changes between updates
* Hardware compatibility issues
* Installation problems
* Features that are changed or removed

**Do not use AetherOS as your only operating system if you rely on your computer for important work or data.**

Always keep backups of anything important.

## 🐛 Reporting Issues

Issues, bug reports, feature requests and suggestions are welcome!

If you find something wrong, please open an issue on GitHub with as much useful information as possible.

When reporting a bug, try to include:

* What happened
* What you expected to happen
* Steps to reproduce the problem
* Your AetherOS version
* Relevant logs or error messages
* Hardware information where relevant

### ⏳ Please Be Patient

Please **don't expect an immediate response or fix**.

AetherOS is a **one-person project**. Development, testing, packaging, documentation, support and issue management are all handled by me.

Some issues may take **days, weeks, or potentially longer** to investigate and fix.

Some feature requests may also never be implemented depending on their complexity, usefulness, development time, or compatibility with the direction of AetherOS.
